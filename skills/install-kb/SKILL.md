# 安装速查知识库 — 总指导（必读）

## 定位

这是**用户个人的、自进化的**速查知识库：`skills/` 下每个子目录 = 一个工具模块，记录
**用户实测跑通**的安装命令（每条附作用）、用法、注意事项、踩坑解法。

三条铁律：

1. **只信库内记录**：命中模块就严格按记录执行/回答，**禁止给用户没用过、未经验证的
   泛化方案**，禁止从零推导瞎试。
2. **查询优先**：用户模糊回忆（「我以前是不是装过 X / 当时那个问题怎么解决的」）也先搜
   `skills/` 再答；搜不到就如实说库里没有记录。
3. **自动进化**：库里没有的需求/命令/坑，现场解决后**不等用户吩咐**，自动按模板收录
   （新建模块或追加），并告知用户「已收录/已更新 `skills/<模块>`」。

## 单个模块：查 / 装

1. **定位**：在 `skills/` 下按名字/别名找 `<模块>/SKILL.md`（如「装 clash」→ `skills/clash/`）。
2. **命中** → 按模块内「安装（上次实测命令）」执行或给用户。
3. **多个相似模块**（如几个 clash 变体）→ 列出来问用户装哪个。
4. **装前看顶部「配套」**：缺依赖先装依赖，依赖同样先查库。
5. **没有记录** → 正常安装；装通后按下方模板新建 `skills/<模块>/SKILL.md`（铁律 3）。

## 多个模块：连续安装搭环境

用户报一串模块（如「clash + node + docker 搭个环境」）时：

1. 逐个读取各模块 `SKILL.md`；
2. 按各自「配套」关系排出安装顺序；
3. 逐个安装，**每装完一个先过它的「验证」，通过再装下一个**；
4. 全部完成后统一回写各模块的「更新记录」。

## 模块 SKILL.md 模板

```markdown
---
name: <模块名>
description: <模块> 的安装与用法速查。当用户要安装/使用 <模块> 或问其命令细节时使用（先读 skills/install-kb）。
---
# <模块> 速查

配套：<依赖/常一起装的模块；无则写 无>

## 安装（上次实测命令）
上次真正跑通的命令序列，每条附一句作用说明。

## 用法
常用命令 + 各自作用。

## 验证
装完怎么确认真的可用。

## 踩坑与解决
现象 → 原因 → 解决办法。

## 更新记录
<日期> <环境>：本次实测结果 / 新增的坑。
```

## 回写规约（进化的唯一来源）

**任何环境遇到新冲突/新坑并解决后，必须回写对应模块的 SKILL.md：**

- 「踩坑与解决」追加：现象 → 原因 → 解决办法；
- 「安装（上次实测命令）」更新为本次跑通的序列（含被环境改动的值，如探测到的真实端口）；
- 「更新记录」追加一行，**累加不覆盖**（保留历史，能看出不同环境的差异）；
- 回写后告知用户「已更新 `skills/<模块>`」。

## 跨平台

本库为纯 Markdown + Agent Skills 标准布局（`skills/<模块>/SKILL.md`），不绑定任何平台：

- 任何 agent 克隆本仓库后直接读本目录即可用；仓库根 `AGENTS.md` / `CLAUDE.md` 已指路。
- 也可用 `npx skills@latest add <本仓库>` 把模块装进各平台各自的技能目录。
