### 项目定位与用途

Sphere 是面向 Unicity network 的 Web3 钱包与代理平台，官方简介称其提供“双层加密钱包、私信、群聊和市场”。从已给出的摘录看，它不仅承担资产管理功能，也把外部 dApp、消息与代理界面整合到同一套应用中，作为用户在 Unicity 生态中的统一入口。

### 解决的问题

该项目主要解决 Web3 场景下钱包、通信与应用跳转分散的问题。它把链上资产操作、DApp 连接、消息沟通和代理加载放在一起，减少用户在多个工具间切换的成本；同时通过权限审批、深链和实时通知等机制，降低外部应用接入钱包时的交互门槛。

### 使用场景

典型场景包括管理 ALPHA blockchain 上的钱包、查看交易历史、执行代币转账，以及在 Unicity state transitions 上进行快速低成本的代币管理。目标用户还包括需要通过钱包连接 dApp 的使用者、在 Nostr 上进行私信的用户、使用 NIP-29 群聊的社区成员，以及在聊天中打开 `unicity-connect://` 深链并进入外部应用的用户。

### 技术架构与特性

从 README 摘录可见，Sphere 采用多层钱包架构，覆盖 Layer 1 与 Layer 3，并支持 L1-L3 bridge、二维码、钱包切换和助记词管理。它实现了 Sphere Connect 的 `ConnectHost`，支持 iframe 与 popup 两种连接模式、基于权限的访问审批和意图处理；同时通过自定义 `unicity-connect://` 协议、Markdown 解析与全局导航处理实现深链跳转。近期提交还显示项目持续更新 `@unicitylabs/sphere-sdk`。

### 项目定位与用途

这是一个演示型开源项目，用于展示如何在浏览器应用和 Node.js 应用中集成 Sphere Connect 协议。它以示例方式说明 dApp 如何通过 ConnectClient 与钱包侧的 ConnectHost 通信，实现余额查询、代币发送、消息签名等交互，而不直接暴露私钥。项目包含浏览器端 React dApp 示例和 Node.js CLI 客户端示例。

### 解决的问题

该项目主要解决 Web dApp 与 Sphere 钱包之间如何安全、类型化通信的问题。传统钱包交互往往涉及复杂的连接逻辑、不同运行环境的兼容性，以及用户授权后的持续通信。Sphere Connect 通过 RPC 方式封装查询、意图和事件，帮助开发者理解如何在不接触私钥的前提下完成读取资产、发起交易和接收实时事件等流程。

### 使用场景

适合需要对接 Sphere 钱包的前端开发者、dApp 开发者，以及希望验证协议流程的集成测试场景。浏览器示例可用于本地运行 React 页面并连接已打开的钱包或扩展；Node.js 示例则展示 CLI 客户端与 mock wallet server 的联调方式。它也适合学习自动连接、弹窗连接和 iframe 嵌入等不同接入方式。

### 技术架构与特性

项目分为 browser 和 nodejs 两部分，browser 端基于 Vite、Tailwind 的 React 示例，nodejs 端包含 CLI 客户端与 mock wallet server。它展示了三优先级传输选择：iframe 内使用 PostMessageTransport、安装扩展时使用 ExtensionTransport、否则通过弹窗与钱包通信。示例还覆盖查询、意图、实时事件订阅，以及页面加载时的静默自动连接机制。
