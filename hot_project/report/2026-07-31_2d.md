### 项目定位与用途

mattpocock/skills 是 Matt Pocock 开源的一套“AI 编码 agent 技能”（Agent Skills）集合，而不是个人技能/简历清单。作者把自己每天做真实工程（而非“vibe coding”）所用的斜杠命令与技能，以 SKILL.md 形式沉淀出来。可用 `npx skills add mattpocock/skills` 安装到 Claude Code、Codex、Cursor 等任意兼容 Agent-Skills 标准的 harness，或作为 Claude Code 原生插件订阅。技能被刻意做得小巧、可组合、模型无关，鼓励使用者按需改成自己的版本。

### 解决的问题

它针对编码 agent 的四类常见失效：①做出来的不是你要的——用 /grill-me、/grill-with-docs 反复逼问、对齐需求；②输出过于啰嗦——借 CONTEXT.md 建立项目共享领域语言，减少歧义与 token 消耗；③代码跑不通——/tdd 走红-绿-重构、/diagnosing-bugs 做系统化排障；④架构劣化成“烂泥球”——/improve-codebase-architecture、/codebase-design 定期治理。核心理念是把软件工程基本功固化成可复用、可组合的流程，而非交给某个大而全的框架接管。

### 使用场景

适合任何用 Claude Code/Codex/Cursor 等 agent 开发真实项目的工程师。典型链路：grill（对齐）→ to-spec（成规格）→ to-tickets（拆票）→ implement/tdd（实现+测试）→ code-review（评审）。技能分两类：user-invoked（你手动 /命令 触发，负责编排，如 grill-with-docs、triage、wayfinder、implement）与 model-invoked（agent 也可自动调用，承载可复用纪律，如 tdd、code-review、diagnosing-bugs、research、domain-modeling）。另有 handoff、teach、writing-great-skills 等生产力技能。

### 技术架构与特性

项目主体是一批 Markdown 的 SKILL.md 及提示词/工作流定义，而非可执行程序；GitHub 语言标签显示的 Shell 只反映少量安装/脚手架脚本，并非其核心。两种安装哲学：skills.sh 安装器把技能拷进你的仓库（可自由修改），或以 Claude Code 插件形式作为只读、随作者更新的托管包订阅。特性在于模型无关、颗粒小、可组合，并区分 user-invoked 与 model-invoked 两种触发方式；配套 CONTEXT.md、ADR 等文档约定，用来沉淀领域语言与设计决策。
