### 项目定位与用途

这是一个面向 Claude 的视频理解技能插件，核心作用是让 Claude “看懂”视频。用户可以输入视频链接或本地视频路径并提出问题，项目会自动抓取字幕、下载所需内容、提取视频帧和时间戳转录，再交给 Claude 进行综合分析与回答。它更像是把视频内容转成 Claude 可处理的多模态信息流，而不是单纯的视频播放器或转码工具。

### 解决的问题

项目主要解决大模型默认无法直接“观看视频”的痛点。仅靠标题或零散字幕，Claude 很难准确理解画面变化、关键动作和上下文；而很多视频又包含大量屏幕信息、操作细节或演示步骤，仅看文本转录会丢失重要内容。该项目通过同时结合字幕、音频转录和帧图像，尽量补足这些缺失信息，让模型能够更接近“看过视频”后再回答。

### 使用场景

适合分析公开视频、广告创意、竞品发布、播客开场、课程片段等内容，也适合处理屏幕录制、报错复现视频或他人发来的故障演示，帮助定位问题出现在哪一帧、屏幕上发生了什么。它也可用于长视频摘要、提炼“真正新增了什么”的更新解读，以及把播放列表或课程系列整理成可检索笔记。目标用户主要是使用 Claude Code、Cursor、Copilot、Gemini CLI 等 Agent Hosts 的开发者和重度信息处理用户。

### 技术架构与特性

根据 README 摘录，项目以 `/watch` 命令提供能力，安装后可在多种 Agent Skills 宿主中使用。它依赖 `yt-dlp` 和 `ffmpeg`，首次运行可自动安装；优先抓取字幕，若视频有字幕则可在较低成本下完成处理，必要时再使用 Whisper API 作为回退。项目支持从公开视频或本地文件读取，提取场景相关帧或快速关键帧，并将每一帧作为图像交给 Claude 读取；近期提交还提到加入帧去重、Whisper 自动分块，以及将其重构为自包含的 Agent Skills 包。
