### 项目定位与用途

Archify 是一个面向 Claude、Codex CLI 和 opencode 的 agent skill，用自然语言把系统或流程描述生成美观的技术架构图。它支持架构图、工作流图、时序图、数据流图和生命周期图，并可在对话中继续迭代修改。生成结果是一个自包含的 HTML 文件，可直接打开、切换深浅色主题，并导出为 PNG、JPEG、WebP 或 SVG。

### 解决的问题

它主要解决“不会画图也能把技术设计表达清楚”的问题。对很多系统设计、流程说明、调用链分析或数据边界说明来说，手工制图耗时且需要设计能力；Archify 让用户只需用英文描述组件和关系，就能得到结构化、可分享的图。它还减少了导出多种格式、适配深浅色和保持清晰度时的重复工作。

### 使用场景

适合系统设计讨论、云架构说明、CI/CD 流程梳理、请求链路展示、数据管道和 PII 边界表达，以及 runbook、审批流、状态机等技术流程图场景。目标用户包括开发者、架构师、技术写作者，以及在聊天中快速产出可展示图示的 AI 工具使用者。README 仅给出了这些典型方向，未提供更具体行业案例。

### 技术架构与特性

从已给信息看，它以“单个 HTML 文件”作为输出载体，强调零依赖、可直接分享。生成过程带有验证闭环，包括 JSON schema 验证、布局检查、HTML/SVG 产物检查和针对性迭代。它支持语义化技术标签，如 aws.lambda、postgres、redis 等，能自动映射到合适的视觉类别；SVG 还会跟随系统深浅色偏好。近期提交显示其 CLI、布局与验证提示仍在持续完善。
