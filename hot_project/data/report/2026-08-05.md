### 项目定位与用途

pdf-inspector 是 firecrawl 旗下的一个快速 Rust PDF 处理库，核心定位是对 PDF 进行分类、文本提取和转 Markdown，并能智能判断文档是文本型、扫描型、图片型还是混合型。它强调在本地完成解析，不依赖 OCR 或外部服务，并提供 Python、Node.js 和浏览器 WebAssembly 绑定，便于在多种运行环境中使用。

### 解决的问题

该项目主要解决 PDF 自动处理中的“是否需要 OCR”和“如何高效提取可用文本”两个痛点。它通过快速采样内容流来识别不同 PDF 类型，并返回置信度与按页路由信息，帮助调用方把扫描件送去 OCR，把文本型 PDF 直接走本地抽取，从而减少不必要的计算开销与外部服务成本。README 还提到它面向约 54% 不需要 OCR 的 PDF。

### 使用场景

适用于需要批量处理 PDF 的检索、解析、归档和文档转换场景，尤其是希望在本地快速完成前置分流与文本抽取的系统。典型用户包括需要做 OCR 路由决策的服务端应用、在 Python 或 Node.js 中集成 PDF 解析能力的开发者，以及希望在浏览器或 Web Worker 中离线处理 PDF 的前端场景。README 中还提到它可输出更适合后续处理的 Markdown。

### 技术架构与特性

项目以纯 Rust 实现，PDF 解析依赖单一库 lopdf，强调轻量和无模型依赖。它支持一次加载文档并复用到检测与抽取流程，减少重复 I/O；支持带位置信息的文本抽取、自动多栏阅读顺序、RTL 文本、CID 字体与 ToUnicode CMap 解码；还支持标题、列表、代码块、表格和页分隔的 Markdown 转换。README 与近期提交记录显示，它也在持续完善表格、布局、密码保护 PDF 和绑定类型同步等能力。

### 解决的问题

### 使用场景

该项目适用于对数据隐私有极高要求的本地化 AI 应用，如个人助理、企业私有知识库助手或离线运行的智能机器人。目标用户包括希望构建自主智能体的开发者、关注数据安全的科研机构以及需要在无网络环境下部署 AI 服务的场景。此外，它也适合需要低成本、高并发处理记忆请求的开放平台插件开发者，特别是那些希望集成 OpenClaw 插件生态以增强 Agent 记忆能力的技术团队。

### 技术架构与特性

项目采用四层渐进式管道架构，结合向量搜索与嵌入技术，实现高效的本地记忆管理。其核心特性包括完全本地化运行，无需任何外部 API 支持，确保数据主权。技术栈涵盖 LLM 集成、Embedding 模型及向量数据库技术，支持长短期记忆的分级处理。作为 OpenClaw 插件生态的一部分，它提供了标准化的接口，便于与其他 Agent 框架无缝对接，实现了从数据写入到检索的全流程自动化与高性能优化。
