### 项目定位与用途

colibri 是一个轻量级的 MoE 推理引擎，目标是在约 25GB 内存的消费级机器上运行 GLM-5.2（744B 参数）。它以纯 C 实现、零依赖运行，通过从磁盘流式加载专家权重来支撑“微小引擎、巨大模型”的使用方式，定位更偏向高效本地推理与模型服务。

### 解决的问题

它主要解决超大规模 MoE 模型对显存和内存要求过高、普通机器难以部署的问题。项目将 VRAM、RAM 和存储视为统一的分层内存体系，密集部分常驻内存，路由专家按需从磁盘流式读取，从而在 fast memory 不足时优先牺牲速度而不是悄悄改变模型精度或路由语义。

### 使用场景

适合希望在消费级硬件上本地体验或部署 GLM-5.2 的开发者和研究者，也适合需要可视化监控推理过程的场景。README 提到可通过 `./coli chat` 进行对话，也提供 `./coli web` 的网页仪表盘，用于查看实时 token、硬件与专家分层信息，适合实验、演示和本地服务。

### 技术架构与特性

项目核心是一个约 2400 行的单文件 C 引擎 `c/glm.c`，搭配少量头文件，运行时无 Python、无 BLAS、无额外依赖，并且不要求 GPU。README 还提到它实现了 GLM-5.2 的 forward、MLA attention、压缩 KV-cache、DeepSeek-V3 风格路由器、原生 MTP speculative decoding，以及按层 LRU 缓存、可选热数据驻留和磁盘流式专家加载等特性。
